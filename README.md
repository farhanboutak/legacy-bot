# Legacy State Roleplay Discord Bot

A professional Discord bot for Legacy State Roleplay community management.

## Features

- **User Control Panel** - Account management and verification
- **Character Management** - View and manage game characters
- **Admin Commands** - User management, economy control, moderation
- **Giveaway System** - Create and manage giveaways
- **Report System** - Player and bug reporting
- **Suggestion System** - Community feedback collection
- **Server Information** - Real-time server status and stats

## Installation

1. Clone the repository
2. Install dependencies: `npm install`
3. Configure `.env` file with your credentials
4. Run the bot: `npm start`

## Configuration

Create a `.env` file with:

```env
TOKEN=your_discord_bot_token
GUILD_ID=your_server_id

DB_HOST=your_host
DB_USER=your_password
DB_PASSWORD=your_password
DB_NAME=your_db

SERVER_IP=127.0.0.1
SERVER_PORT=7777
